# Security Policy

## Scope

Applies to all Kinetech Labs repositories.

---

## Reporting Security Issues

Do not open public issues for security vulnerabilities.

Report privately to:

- Founders

Include:

- Description of issue
- Affected system or module
- Steps to reproduce
- Potential impact

---

## Response Process

- Acknowledge within 24–72 hours
- Severity triaged immediately
- Critical issues are prioritized for immediate fix

---

## Notes

Security issues must remain confidential until resolved.
