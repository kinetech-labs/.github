# Code of Conduct

## Principles

- Respect each other’s time and work
- Communicate clearly and directly
- Focus on solutions, not blame
- Share context early
- Keep discussions professional

---

## Collaboration

We value:

- Clear thinking
- Honest feedback
- Fast iteration
- Ownership of work

---

## Conflict Resolution

Disagreements should be resolved in:

- Pull request discussions
- Structured technical conversations

Not in informal chat arguments.

---

## Standard

Work is reviewed based on quality and impact, not hierarchy.
